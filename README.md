## ✨ Overview

**MAX STUDIO** is an open-source Android music app built around flexible listening and deep personalization. Explore music, play local tracks, follow synchronized lyrics, listen together with friends in real time, and shape the interface to your own style.

| Detail | Value |
|:--|:--|
| Current source version | `1.5.18` (versionCode `189`) |
| Android package | `com.max.music` |
| Minimum Android | Android 8.0 · API 26 |
| Target / compile SDK | 36 / 37 |
| Languages & UI toolkit | Kotlin · Jetpack Compose · Material 3 |
| Build variants | FOSS and GMS, universal and per-ABI |
| License | GNU GPL v3.0 |

## 🚀 Features

### 🎧 Playback
- Background playback with full queue controls
- Crossfade and gapless playback
- Skip silence, tempo and pitch control
- Equalizer and audio normalization options
- Sleep timer
- Local music support and offline downloads
- USB audio support and Google Cast (GMS build)
- Home-screen widgets

### 📝 Lyrics
- Synchronized lyrics with several display styles
- Multiple lyrics sources (LRCLIB, Better Lyrics, KuGou, SimpMusic, Unison and more), with optional translation-provider integrations

### 🔎 Discovery and integrations
- Browse and discover music, plus **Echo Find** music recognition
- Last.fm and ListenBrainz scrobbling
- Spotify import and Discord Rich Presence
- Canvas (looping visuals) support

### 🎨 Personalization
- Material 3 styling, **Liquid Glass** effects, ambient mode
- Multiple player layouts, themes, custom fonts and launcher icons
- **Music Flow** navigation: swipe between tabs with a compact floating bar
- Haptics settings and blocked-artist controls
- Backup and restore, storage management
- Translated into many languages

### 🤝 Social
- **Listen Together:** real-time rooms where everyone hears the same track, with a shared queue and live chat (details below)

> Some features need a network connection, an account, or an API key. Third-party service behavior and availability can change independently of MAX STUDIO.

## 🎵 Listen Together

Create a room, share the code or invite link, and listen to the same track in sync.

| Capability | Description |
|:--|:--|
| Rooms | Host creates a room; friends join with a code, link or QR code |
| Instant join | Join requests are approved automatically for the host |
| Sync | Play, pause, seek, track changes and queue updates mirror across devices |
| Buffer sync | Guests report when a track is ready so playback starts together |
| Chat | Live room chat for everyone in the room |
| Controls | Host can allow guests to control playback, kick users, or hand over host |
| Reconnect | Dropped users can rejoin their room within a grace period |

### Architecture

```mermaid
flowchart LR
    A[Host app] -- WebSocket --> W((Cloudflare Worker))
    B[Guest app] -- WebSocket --> W
    C[Guest app] -- WebSocket --> W
    W --> D[(Durable Object<br/>room state)]
    D -- sync_playback / chat / buffer --> A
    D -- sync_playback / chat / buffer --> B
    D -- sync_playback / chat / buffer --> C
```

The backend runs on **Cloudflare Workers** with a **Durable Object** that holds room state. The same Worker also serves share and invite links, the Android App Links verification file, and the canvas list. The default server can be changed in **Settings → Integrations → Listen Together**.

## 📲 Download and install

1. Open [GitHub Releases](https://github.com/kryvexo/MAX-STUDIO-/releases/latest).
2. Download the latest Android APK.
3. Open the APK and follow Android's install prompts. You may need to allow your browser or file manager to install apps.

> **Updating:** Android only updates an installed app if the new APK has the same package ID and the same signing certificate. If Android refuses an update because the signing key differs, back up your data (Settings → Backup and restore) before uninstalling the old version.

## 🛠️ Build from source

### Requirements
- Android Studio or Android SDK command-line tools
- JDK 21
- Android SDK Platform 37 and matching build tools
- Git

### Clone and configure

```bash
git clone https://github.com/kryvexo/MAX-STUDIO-.git
cd MAX-STUDIO-
cp local.properties.template local.properties
```

Set your SDK path in `local.properties`:

```properties
sdk.dir=/path/to/your/Android/Sdk
```

On Windows use `gradlew.bat` instead of `./gradlew`.

### Build variants

| Flavor | Notes |
|:--|:--|
| `foss` | No Google Play Services dependent features (for example Cast) |
| `gms` | Includes Google-dependent integrations |
| `universal`, `arm64`, `armeabi`, `x86`, `x86_64` | ABI variants |

```bash
# Universal FOSS debug APK
./gradlew assembleUniversalFossDebug

# Universal GMS debug APK
./gradlew assembleUniversalGmsDebug

# Unit tests
./gradlew :app:testUniversalFossDebugUnitTest
```

APKs are written to `app/build/outputs/apk/`.

### Release signing

A release APK needs **your own** signing key. Keep the keystore and passwords private and **never commit them**.

```bash
export KEYSTORE_PATH=/path/to/release-key.jks
export KEY_ALIAS=your_key_alias
export STORE_PASSWORD=your_store_password
export KEY_PASSWORD=your_key_password
./gradlew assembleUniversalGmsRelease
```

**CI (GitHub Actions):** add the repository secrets `KEYSTORE_BASE64`, `KEY_ALIAS`, `STORE_PASSWORD` and `KEY_PASSWORD`. When `KEYSTORE_BASE64` is present, the workflow produces a signed release APK; otherwise it builds a debug APK.

Always use the **same keystore** for every release, otherwise users cannot update in place.

## 🗂️ Project structure

| Module | Purpose |
|:--|:--|
| `app` | Main Android application: UI, navigation, settings, Listen Together client |
| `core`, `domain` | Shared data layer, database entities and domain models |
| `playback` | Playback engine and service integration |
| `innertube`, `metadata` | Music catalog and metadata access |
| `lyrics`, `lrclib`, `betterlyrics`, `kugou`, `simpmusic`, `unison`, `paxsenixlyrics`, `youlyplus` | Lyrics engine and individual lyrics providers |
| `canvas`, `echomusiccanvas`, `applecanvas`, `artistvideo` | Canvas and artist visuals |
| `shazamkit` | Music recognition (Echo Find) |
| `audio-dsp`, `dsp-core`, `usbaudio` | Audio processing and USB audio output |

Further reading: [`SETUP.md`](SETUP.md) · [`DESIGN.md`](DESIGN.md) · [`CONTRIBUTING.md`](CONTRIBUTING.md) · [`RELEASE_INFO.md`](RELEASE_INFO.md)

## 🔐 Privacy and third-party services

Read [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md) for the project's stated data practices. MAX STUDIO may connect to third-party services you choose to use. The download counter in the About page requests public release metadata from GitHub. It counts total downloads, not unique or active users, and GitHub receives ordinary request metadata such as the device's IP address.

Listen Together sends room messages (playback state, track info, chat) through the Listen Together server you select.
